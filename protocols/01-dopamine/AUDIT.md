## 7. What the annotations do and do not establish

Established by the table: the four ER4m rows carry the `neurotransmitter_verified` string `gaba,dopamine`, so `dopamine` is an explicit token in a column named verified, in second position. The same four rows carry `neurotransmitter_predicted` = `gaba` with scores 0.9501, 0.9517, 0.9569, 0.9633. Among all 380 modulation sources, dopamine is the only token for 354, the first of several for 16, and not first for 10. The dual use of the ten sources follows from the two parsing rules and is reproduced here from the committed arrays.

Not established by the table: where the label came from. The file has no column giving a source, method, citation, annotator or date for `neurotransmitter_verified`, for any row. It does not say whether the label was assigned to the individual neuron or inherited from its cell type, what the token order means, or whether a second token denotes cotransmission onto the same targets. The table therefore contains an explicit dopamine label for all four ER4m neurons and no stated source for it. Whether that satisfies the keep condition in `PROTOCOL.md` ("an explicit dopamine label with a stated source") is a decision made before protocol 02.
